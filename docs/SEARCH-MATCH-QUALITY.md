# 企業検索の条件判定修正（2026-10-12）

既存の検索を改修し、指定条件が不明な企業を条件一致に数えないようにした。業種は従来の日本標準産業分類の大分類のまま。保存済み候補や検索条件、電話調査・営業リスト取込の仕組みは維持する。

## 条件一致と情報不足

- 人数の範囲や業種を指定した場合、既知の値が条件を満たす企業を「条件一致」に表示する。
- ほかの条件を満たすが指定した人数・業種が不明な企業は「情報不足（別枠）」に表示する。既存の未確認を残す設定が有効な項目だけが対象。未確認を除外する設定と「従業員数あり」は維持する。
- 既知の条件不一致は優先して除外する。例えば人数不明でも業種が指定と異なれば、情報不足の別枠にも表示しない。
- 人数の条件がない場合、人数不明だけを理由に情報不足にはしない。人数0は不明と区別する。業種「未確認」を明示的に選ぶ既存フィルターも維持する。
- 一覧APIと外部取得時のカウンターに同じ判定を適用する。業種コード一致、社名・事業内容のキーワード一致、不足項目を別々に表示する。語句の一致から業種や営業ニーズを推定確定しない。キーワード内はOR、それ以外の条件間はAND。

## 取得量と表示範囲

外部取得は条件一致と情報不足の合計20社で一旦止める。5社一致・15社不明なら合計20社で停止する。不明を分離した結果、厳密な一致20社まで自動的に取得を増やすことはない。

上限200件（取得位置数）、20件ずつ最大10ページ、25秒の実行枠、枠ごとの詳細5件・検索2回、30秒の取得間隔、逐次処理、組織あたり5,000候補の制約は変更しない。重複は確認位置数を消費するが一致・情報不足は重複計上しない。取得済み候補は条件不一致でも従来どおり保存され、表示変更では削除しない。

200件の上限到達は「この範囲の結果・全件確認済みではない」と表示する。取得元が返す範囲の末尾と、確認目安の達成も別表示。既存の保存済み一覧のページ送りは維持し、外部取得の継続と区別する。別枠への切替や一覧ページ送りで外部取得は発生しない。

## 途中再開の互換性

署名付き取得カーソルをv2に変更し、条件一致IDと情報不足IDを別配列で保持する。旧v1には不明を含む一致数が入っているため、そのまま再開せず409で拒否する。ブラウザーの検索チェックポイント保存キーもv2にする。導入時は旧チェックポイントからの再開ができず、必要なら利用者が新しい検索を開始する。

保存済み候補・保存した検索条件は残る。アクティブ実行を示す保存キーは変更せず、旧画面からの実行も停止処理の対象に保つ。カーソルの組織・条件拘束と有効期限は維持する。DB変更・移行はない。

## 残る限界・別作業

この変更は「条件が合わない企業を一致に見せる」問題を直す。未取得企業の網羅性、データにない人数・業種、電話番号の取得率は改善したと主張しない。細かい業種の分類は追加しておらず、業務効率化の需要を保証するものでもない。実企業・公式サイトの追加取得、実電話番号の確認、本番DB操作、公開は実施していない。
