# 外部企業検索・営業リスト取込

2026-10-05。既存V1に `/discover`（企業を探す）を追加し、本番公開済み。実Gビズ取得・県/業種検索・営業リスト取込まで本番で成功。公開先・証跡・運用上の制限は [本番公開記録](PRODUCTION-RELEASE-2026-10-05.md) を参照。

中小企業向けのプリセット、人数範囲、事業内容キーワード、条件保存については [営業向け検索条件](SME-TARGETING-SEARCH.md) を参照。

## 利用の流れ

1. 都道府県・企業名・法人番号を指定してGビズインフォから候補を取得する。20社単位で、続きの取得は明示的に実行する。
2. 保存した候補を都道府県×業種、名称・法人番号、電話/Webサイト/従業員数の有無で検索する。並び替え・ページ送り・条件解除に対応。
3. 候補詳細で出典・取得日時を確認する。電話・Webサイト・従業員数は手動確認して保存できる。公式サイトからの補完結果は提案として表示し、人が採用する。
4. 最大50社を選んで営業リストへの取込内容を確認する。同じ法人番号は登録済み企業へリンクし、同名・同じ電話の既存企業や選択候補は重複候補として確認する。
5. 取り込んだ企業から、そのまま既存の架電記録・活動・タスクなどへ進む。既存企業への架電はCRMに保存済みの名称・電話を使用し、外部候補の値に置き換えない。候補から削除しても、取り込んだCRM企業・活動・取込時の出典記録は残る。

最初の対象は法人・本店所在地。情報が欠けている企業も表示する。0人と従業員数不明は区別する。店舗・支店モデル、従業員数の単体/連結の推定、自動有料切替は含まない。

## データ範囲と取得制限

- GビズインフォAPIには業種検索パラメータも電話番号項目もない。業種の絞込みは保存済み候補に適用される。全国全企業を網羅する検索ではない。
- API検索は1回20社、ページ1〜10。細かな地域・企業名に条件を分けて取得する。次ページの案内は受信件数から判断するため、次ページが0件になる場合がある。
- 業種はGビズ公式検索画面の日本標準産業分類A〜Tに対応付け、取得元のコードも出典情報内に保持する。GEPS営業品目の数値コードを業種に読み替えない。不明と「T 分類不能」は分ける。
- APIの基本検索後、最大4並列で詳細を取得する。1呼出10秒、全体の詳細取得開始に32秒の期限、応答2MiB上限。失敗した詳細は不明として残し、既知の値・項目別の古い取得日を消さない。
- 候補は1組織5,000社まで。取得は1組織30秒に1回。公式サイト確認は1組織1時間20回。上限をDBで保持し、サーバーの再起動・並行呼出しでも制限する。
- 取得を再開するページは組織・検索条件ごとにブラウザーへ記録。企業候補や確認結果はDBに保存される。

## 出典と手動修正

候補には取得元、元データ更新日、取得日、項目別の出典と取得日、業種の元コード、手動確認した項目を保存する。従業員数の集計範囲は元資料で確認する。

手動修正したWebサイト・従業員数はGビズの再取得で上書きしない。詳細取得に失敗して既知値を残す場合、その値の出典・取得日も保持する。公式URLが変わった場合は旧サイトの未採用の補完提案を破棄する。CRMの既存値は取り込みで上書きしない。

## 公式サイトの補完

候補に登録された公式URLに対する明示操作のみ実行する。公開ページから、電話/TEL表示や電話リンク、明示された従業員数を確認候補として返す。社名だけで公式サイトを推定したり、数字から従業員数を推測したりしない。

- 公開IPのDNS検証と接続先固定、同一ホストの転送再検証。内部アドレス・認証情報付きURL・特殊ポート等は拒否。
- robots.txt、ページ内の取得拒否表示、403/429、認証・CAPTCHAを尊重。拒否や確認不能では停止する。
- 最大8秒、各1MiB、robots＋最大2HTMLページ、合計2回までの転送。自動再試行しない。
- 電話と従業員数を別ページから拾った場合に単一の出典へ混在させない。出典URLと短い根拠を表示し、採用する値は人が確認する。

個別サイトの利用条件や掲載状況により取得できない場合がある。公式サイト側の収録率・正確性は保証しない。

## 権限・整合性

- 候補と取込記録は組織ごとにRLSで分離。閲覧者は保存済み候補のみ閲覧でき、取得・補完・編集・削除・取込は不可。
- ログアウト済み・失効セッションのJWTでも書込みを拒否。
- 取込はDBトランザクションと既存CRMの組織ロックを使用。法人番号一意制約で同時取込・再送の二重登録を防ぐ。
- 取込前の候補・重複状態の変更はレビュー情報で検出する。編集は `updated_at` 一致で更新し、古い画面から上書きしない。
- 取込時の候補スナップショットを組織内の読取り専用記録に残す。候補の再取得・削除でも消えない。
- サーバー専用 `GBIZ_API_TOKEN` を使用。ブラウザーに渡さず、ログ・例外にも出力しない。
