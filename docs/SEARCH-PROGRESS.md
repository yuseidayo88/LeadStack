# 企業検索・電話番号調査の進捗表示

2026-10-07。既存検索と電話番号調査に追加したローカル実装。本番未反映。

## 表示と完了の定義

- 企業検索を押した直後、最初の応答ヘッダーや進捗イベントを待たずに「検索中…」を表示する。実行中は二重開始を防止する。
- 企業検索のバーは「確認済み / 上限200社」と「条件一致 / 目標20社」。サーバーから受け取った件数だけを使用する。総件数・所要時間が未確定なので、時間に対する進捗率や終了予定時刻は表示しない。
- 条件一致の目標、200社の上限、取得範囲の終端のいずれかで終了する。終端が8社なら確認数は8/200のまま完了を表示し、100%に増やさない。
- 経過時間と、サーバーの `nextAllowedAt` に基づく「次の確認まであとN秒」を表示する。後者は次の取得までの待機時間であり、検索全体の残り時間ではない。
- 最終イベントだけでは完了にしない。ストリームのEOFと一覧の最終再取得を待ち、「結果を一覧に反映中…」を表示する。検索中・一覧更新中は空リストの案内を出さず、読み込み状態にする。取得済みの実データがある場合は閲覧できる。
- 停止要求中、停止確認失敗、停止後、外部取得エラー、一覧更新エラーを区別する。既存の取消確認ゲートとrun世代の分離を保持する。
- 「さらに20社を探す」は次の目標件数が応答するまで目標バーを未確定として扱う。確認済み件数は保持する。
- 電話番号調査は「処理済み / 対象社数・残りN社」のバーと経過時間を表示する。対象は最大10社で固定。途中停止・エラー時は未実行分を残し、完了100%にはしない。処理済み件数は電話取得成功数とは別で、再利用・未検出・失敗等を含む。

進捗バーに accessible name と min/max/current値を設定し、処理量未確定のバーにはcurrent値を設定しない。状態変化はpoliteなライブ領域で通知し、毎秒の時計はライブ通知しない。新しいバーのアニメーションはreduced motionに従う。
