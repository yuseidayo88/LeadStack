## 変更した動作

ダッシュボードの「今日」「期限超過」「再架電」を、タスクIDが重複しない一つの「対応するタスク」一覧にした。同じタスクが複数の取得区分に含まれる場合は更新日時の新しい行を採用し、未完了のみを期限順に並べる。今後の再架電と期限未設定の再架電も残す。期限区分はAPIが返す日付の日本時間の境界を使用し、端末のタイムゾーンには依存しない。

APIの取得範囲は従来どおり、自分に割り当てられた各区分の先頭30件。いずれかが30件に達した場合は表示制限を明示し、全件を確認する既存タスク一覧へ案内する。数字を全タスク件数として扱わない。完了操作は既存の更新バージョン照合付きAPIと再取得を使う。

営業リストとタスク一覧は768px未満でカード表示にし、電話・架電・企業詳細・期限・完了・編集に横スクロールなしでアクセスできるようにした。デスクトップ表、絞り込み、並び順、選択、表示項目の切替、ページ送り、削除確認は維持する。
