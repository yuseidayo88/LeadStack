# 電話調査の認証/CAPTCHA誤検出の修正（未公開）

2026-10-07。公開版 `5822473` を基点とするローカル修正。追加の実サイト取得、検索、電話保存、CRM取込、設定変更、push、再公開は行っていない。

## 原因の区別

公開試験の北陸築炉保温工業株式会社（`https://hokurikuchikuro.co.jp/`）は `blocked` と「認証またはアクセス確認が必要なページのため、取得を停止しました。」を返した。この文言はHTMLの文字列検査によるアプリ側の判定で、HTTP拒否、robots、SSRF、timeoutの文言とは異なる。元のHTMLを保存していないため、実際の認証画面か通常のページ内の文字列による誤検出かは未確定。今回そのサイトを再取得していない。

一方、合成HTMLで正常な会社情報に以下を加えると、旧コードが電話番号を抽出せず `blocked` にすることを再現した。

- CAPTCHA/reCAPTCHAに関する説明文や記事リンク
- CAPTCHAの設定変数、CSS、JSON-LD、コメント
- script内のパスワードフィールドの説明文字列、未使用のtemplate

9ケースとも文字列が存在するだけで拒否されていた。実サイトで同じ原因だったという証明ではない。

## ローカル修正

HTML全体の単純な `captcha` / `name=password` 検索を、文脈を限定した判定に置き換えた。

- script/style/comment/templateの説明文字列を公開の入力欄として扱わない。
- password入力欄、CAPTCHAウィジェット/応答欄、認証iframe/image、具体的な認証スクリプトの読込み・呼出し、人間確認の指示は引き続き拒否する。
- noscript側の認証表示も検査する。既知のTurnstileや型だけでpasswordを表す入力欄など、旧判定が見逃したケースも拒否する。
- 認証ウィジェットが会社情報と同居していても保守的に停止する。公開電話があれば認証判定を無視するという例外は作らない。
- JavaScript実行、CAPTCHA解決、フォーム送信、認証用iframeへの移動は行わない。

DNS/IPの検査と固定、URL/転送制限、robots/meta/header、8秒、1MiB、最大2HTMLページ、取得枠、24時間キャッシュ、確認して保存する仕組みは変更していない。依存関係・環境変数・DB/Auth/RLS変更なし。

HTMLの文脈判定であり、任意のサイトの認証を完全に識別できるという保証ではない。CAPTCHAの実スクリプトを読み込む会社ページは、公開情報が載っていても引き続き拒否し得る。電話の自動取得率を上げるために保護を広く解除していない。
