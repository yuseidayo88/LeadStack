# よく使う検索条件と個別解除

## 利用方法

- 「保存した検索条件」を開き、「条件を保存」で県・業種・企業名／法人番号・従業員数・未掲載の扱い・業務キーワード・電話／Webの有無・並び順を、40文字以内の名前で10件まで保存する。
- 保存名を押すと条件を復元し、取得済み候補の一覧を絞り込む。外部検索は明示的に検索ボタンを押したときだけ開始する。「取得済みの企業情報も更新する」は復元時にオフにする。
- 「指定中の条件」の各ボタンで、その条件だけを解除する。例：電話番号の条件を外しても、東京都・建設業・人数範囲は維持する。条件変更時はページと企業の選択をリセットする。
- 保存名の横の×は保存した条件だけを削除する。現在の検索条件や企業データは削除しない。同じ名前での暗黙の上書きは行わない。

## 保存範囲と安全性

保存先はこのブラウザーのlocalStorageで、利用者IDと組織を組み合わせて分離する。別端末への同期や組織内共有はない。既存の「直前の検索条件」の自動保存は変更しない。

新しい保存形式はバージョン付きで、保存データ内の利用者・組織も照合する。壊れた条件を勝手に広い条件へ修正して復元せず、無効な項目は無視する。検索条件以外の情報、APIトークン、カーソル、強制再取得フラグは保存対象から除く。

書込直前に最新の保存一覧を読み、Web Locksを利用できるブラウザーでは同一保存先の変更を直列化する。非対応時は通常の同期localStorage書込に戻す。別タブの保存・削除は一覧へ反映するが、そのタブで編集中の検索条件や選択を勝手に変更しない。

保存容量不足などの失敗を表示し、保存成功として扱わない。既存の保存内容は残し、入力を修正・キャンセルできる。検索中・停止確認中の保存条件呼出しは無効。個別解除は従来の条件変更処理を通り、実行中の検索の取消と古い応答の破棄を維持する。

DB／RLS／認証・権限／API仕様／環境変数／依存関係／課金契約の変更なし。既存V1のクライアント画面とローカル保存のみの変更。
